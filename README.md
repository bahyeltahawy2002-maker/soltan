# 🛒 متجر السلطان (Sultan Store)

متجر إلكتروني متكامل وعصري متخصص في بيع وتقديم أفضل منتجات التدخين، المعسل، السجائر، وفيب ومستلزماتها. تم تصميم الموقع ليعمل بسلاسة تامة على جميع الأجهزة ويوفر تجربة تسهل على الزبائن استعراض الأصناف والطلب السريع عبر الواتساب.

---

## 🚀 مميزات المشروع
* **واجهة مستخدم عصرية (UI/UX):** تصميم أنيق وجذاب متوافق مع الهواتف المحمولة وأجهزة الكمبيوتر.
* **عرض منظم للأقسام:** تقسيم المنتجات إلى (معسل، سجائر، فيب، وأكسسوارات).
* **نظام الطلب الفوري:** يتيح للزبون إضافة المنتجات للسلة وإرسال الطلب مباشرة بضغطة زر إلى رقم الواتساب الخاص بالإدارة.
* **لوحة تحكم خاصة للأدمن:** صفحة إدارة محمية بكلمة مرور لتمكين مسؤول المتجر من إضافة، تعديل، أو حذف المنتجات والأسعار بكل سهولة.

---

## 🛠️ تقنيات البناء (Tech Stack)
* **HTML5 / CSS3**
* **Tailwind CSS** (لتنسيق التصميم بشكل عصري وسريع)
* **JavaScript (Vanilla)** (لإدارة السلة، تفاعلات الصفحة، ولوحة التحكم)
